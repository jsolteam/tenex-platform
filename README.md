**Tenex** — высокопроизводительная и отказоустойчивая платформа для напоминаний о приёме лекарств с подтверждением, отслеживающими лицами, FSM-сценариями и детальной аналитикой.

Проект реализован на Go и построен как **workflow-engine поверх FSM + scheduler**, с поддержкой multi-messenger архитектуры и media abstraction layer.
